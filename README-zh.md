# Applied Categories

[English](README.md) | 简体中文

Applied Categories 是一个适用于 **Applied Energistics 2（AE2）** 的 **NeoForge** 附属模组。它为 ME 网络添加分类终端系统，帮助玩家按自定义分类整理和浏览网络中的物品。

> Minecraft 1.21.1 · NeoForge 21.1.x · AE2 19.x

## 功能

| 内容 | 说明 |
| --- | --- |
| **ME 分类终端** | 带有“全部”“未分类”和自定义分类视图的 AE2 终端。你可以创建、重命名或删除分类，将物品分配到分类，并让放入终端的物品自动归入当前分类。 |
| **ME 分类索引器** | 保存分类数据库的设备。放入一张 **ME 分类磁盘** 后即可加载对应数据库；同一个 ME 网络中只能有一个处于活动状态的索引器。 |
| **ME 分类磁盘** | 分类数据库的便携式密钥。数据库通过磁盘 UUID 保存在世界存档中，因此可以把磁盘移动到其他索引器并继续使用原有分类。 |

所有物品均位于 **“lyan”** 创造模式物品栏中，物品栏图标为 AE2 无线终端。

## 使用方法

1. 合成一张 **ME 分类磁盘**。
2. 合成并放置 **ME 分类索引器**，将分类磁盘放入索引器的磁盘槽。
3. 确保分类索引器已连接到 ME 网络，且网络中没有第二个活动的分类索引器。
4. 合成 **ME 分类终端**，并像普通 AE2 终端一样将其安装到 ME 网络上。
5. 打开分类终端，通过顶部标签查看“全部”“未分类”或自定义分类，并使用 `+` / `-` 按钮管理分类。

在自定义分类视图中：

- 按住 `Ctrl` 并点击物品，可将物品分配到当前分类。
- 按住 `Alt` 并点击物品，可将物品从当前分类移除。
- 向终端放入物品时，物品会自动归入当前选中的自定义分类。

## 合成配方

以下配方均为无序合成：

| 产物 | 材料 |
| --- | --- |
| ME 分类磁盘 | 4K ME 物品存储元件 + ME 存储总线 |
| ME 分类索引器 | ME 驱动器 + ME 分类磁盘 |
| ME 分类终端 | ME 终端 + ME 分类磁盘 |

## 运行要求

- Minecraft 1.21.1
- NeoForge 21.1.x
- Applied Energistics 2 19.x（模组 ID：`ae2`）
- GuideME 21.x（模组 ID：`guideme`）

请同时在客户端和服务端安装本模组及上述依赖。

## 安装

1. 安装适用于 Minecraft 1.21.1 的 NeoForge 21.1.x。
2. 下载并安装兼容版本的 AE2 与 GuideME。
3. 将 Applied Categories 的 `.jar` 文件放入游戏或服务器的 `mods` 目录。
4. 启动游戏或服务器。

## 从源码构建

本项目使用 Java 21 和 Gradle 8.8。仓库目前未包含 Gradle Wrapper 启动脚本，因此需要先在本机安装兼容的 Gradle，然后执行：

```bash
gradle build
```

构建完成后，生成的模组文件位于 `build/libs/`。
